Kata Pengantar

Microsoft Word adalah salah satu aplikasi pengolah kata yang paling sering dipakai di sekolah, kampus, dan perkantoran. Surat, laporan, makalah, hingga buku dapat disusun dengannya. Namun, banyak pengguna baru yang baru memakai sebagian kecil dari kemampuan Word, sehingga dokumen yang dihasilkan kurang rapi dan memakan waktu lebih lama untuk dikerjakan.

Buku ini disusun untuk membantu pembaca memulai perjalanan bersama Microsoft Word dengan cara yang mudah dipahami. Setiap pembahasan disajikan secara runtut dan disertai langkah praktis, sehingga pembaca dapat langsung mencobanya di komputer masing-masing. Setiap bab ditutup dengan lembar kerja yang berisi latihan praktik, pertanyaan pemahaman, dan satu tantangan. Meskipun ditujukan bagi pemula, isinya tetap mengarah pada hasil dokumen yang terlihat profesional.

Pembahasan dimulai dari cara membuka Word dan mengenal tampilan utamanya pada Bab 1. Bab 2 membedah menu Ribbon dari tab File hingga Design. Bab 3 membahas langkah awal mengetik yang benar, disusul pengaturan huruf dan paragraf pada Bab 4. Bab 5 mengajak pembaca membuat dan mengelola tabel, sedangkan Bab 6 membahas gambar, bentuk, dan ikon. Bab 7 menjelaskan tata letak halaman, dan Bab 8 menutup dengan cara menyimpan serta mencetak dokumen.

Penyusun berharap buku ini dapat menjadi teman belajar yang bermanfaat bagi siapa pun yang ingin bekerja lebih cepat, lebih rapi, dan lebih percaya diri dengan Microsoft Word. Saran dan kritik yang membangun sangat penyusun harapkan demi penyempurnaan buku ini di masa mendatang.

    Mahir Microsoft Word

    Mengenal Microsoft Word

    Panduan lengkap untuk memulai perjalanan Anda dengan Microsoft Word, dirancang agar mudah dipahami bagi pemula namun tetap terlihat profesional.

    Cara Membuka Microsoft Word

    Ada beberapa cara cepat untuk mengakses aplikasi ini di Windows.

    Melalui Menu Start

    Klik ikon Start (logo Windows), ketik “Word”, lalu tekan Enter.

    Melalui Shortcut Desktop

    Klik dua kali pada ikon Microsoft Word jika tersedia di layar utama.

    Melalui Pin Taskbar

    Jika sering digunakan, klik kanan ikon Word saat terbuka dan pilih Pin to Taskbar agar selalu muncul di baris bawah layar.

    Memulai Dokumen Baru

    Saat pertama kali terbuka, Anda akan dihadapkan pada layar Start Screen.

    Blank Document
    Pilih ini untuk memulai dari kertas putih kosong.
    Templates
    Word menyediakan desain instan seperti Resume, Brosur, atau Laporan yang bisa langsung diedit.
    Recent Documents
    Di sisi kiri, Anda akan melihat daftar file yang terakhir kali Anda buka untuk melanjutkan pekerjaan dengan cepat.

    Mengenal Tampilan Utama (Antarmuka)

    Memahami bagian-bagian Word akan mempercepat kerja Anda. Berikut adalah komponen kuncinya.

    Quick Access Toolbar (pojok kiri atas)

    Berisi ikon untuk perintah cepat yang sering digunakan, seperti Save (Simpan), Undo (membatalkan perintah), dan Redo.

    Ribbon (bagian atas)

    Pusat kendali utama yang terbagi menjadi beberapa tab:

    File
    Mengatur dokumen (Save, Print, Share).
    Home
    Mengatur teks (font, ukuran, warna, paragraf).
    Insert
    Menambah gambar, tabel, atau nomor halaman.
    Layout
    Mengatur ukuran kertas, margin (batas tepi), dan orientasi (Potret/Lanskap).

    Ruler (Penggaris)

    Berada di atas dan samping kiri area kerja. Berguna untuk mengatur indentasi paragraf dan merapikan posisi teks atau gambar secara presisi.

    Area Kerja (Halaman)

    Bagian tengah yang menyerupai kertas putih. Di sinilah Anda mengetik dan menyusun konten.

    Status Bar (baris bawah)

    Memberikan informasi real-time tentang dokumen Anda:

    Page Number
    Menunjukkan halaman berapa Anda berada.
    Word Count
    Menghitung jumlah kata yang sudah diketik.
    View Buttons
    Mengubah tampilan (Read Mode, Print Layout, atau Web Layout).
    Zoom Slider
    Mengatur besar kecilnya tampilan kertas (geser ke + atau −).

    Langkah Dasar Setelah Mengetik

    Agar dokumen Anda aman dan rapi, biasakan melakukan hal berikut.

    Menyimpan file (Save)
    Tekan Ctrl + S, pilih folder penyimpanan, dan beri nama file yang jelas.
    Mengatur jenis huruf
    Gunakan menu di tab Home. Standar profesional biasanya menggunakan Times New Roman (ukuran 12) atau Arial (ukuran 11).
    Mengatur jarak spasi
    Klik ikon Line and Paragraph Spacing di tab Home agar tulisan tidak terlalu rapat dan nyaman dibaca.
    Tips cepat. Gunakan kombinasi Ctrl + N untuk membuat dokumen baru secara instan, dan Ctrl + P jika Anda ingin mencetak (print) hasil kerja Anda.

    Menjelajahi Ribbon dan Menu Utama

    Untuk menguasai Microsoft Word, memahami Ribbon Toolbar adalah kunci utama. Ribbon adalah barisan menu di bagian atas yang mengelompokkan fitur berdasarkan fungsinya.

    Bedah Tuntas Setiap Tab Menu

    Pilih salah satu tab di bawah ini untuk melihat fungsi setiap kelompok perintahnya.

    Ingat. Menu File adalah satu-satunya menu yang membuka tampilan penuh (Backstage View). Tab lain hanya menampilkan barisan ikon di bagian atas layar.
    Mahir Microsoft Word

    Langkah Awal Mengetik Dokumen

    Setelah memahami tampilan menu, saatnya menuangkan tulisan ke dalam lembar kerja. Agar dokumen tidak berantakan di kemudian hari, ikuti langkah-langkah teknis berikut.

    Tahap Persiapan Halaman

    Sebelum mengetik sepatah kata pun, atur “wadah” tulisan Anda agar sesuai dengan standar dokumen seperti A4.

    1. Atur ukuran kertas. Klik tab Layout > Size > pilih A4 (atau ukuran lain yang diinginkan).
    2. Atur margin (batas tepi). Klik tab Layout > Margins > Custom Margins.
    3. Pilih jenis font. Kembali ke tab Home, pilih font yang profesional (misalnya Times New Roman atau Arial) dan ukuran standar 12.

    Standar umum margin: Atas 3 cm, Bawah 3 cm, Kiri 4 cm, Kanan 3 cm.

    Teknik Mengetik yang Benar

    Dalam Word, ada beberapa aturan “tak tertulis” agar format dokumen Anda konsisten.

    Gunakan Enter seperlunya
    Jangan menekan Enter di setiap akhir baris. Word akan otomatis memindahkan kata ke baris bawah jika sudah mentok ke kanan. Gunakan Enter hanya saat Anda ingin memulai paragraf baru.
    Gunakan Tab untuk menjorok
    Untuk memulai kalimat pertama yang masuk ke dalam pada sebuah paragraf, tekan tombol Tab satu kali. Jangan menggunakan spasi berulang kali.
    Satu spasi setelah titik
    Setelah tanda titik (.) atau koma (,), berikan satu kali spasi sebelum memulai kata berikutnya.

    Mengatur Perataan Teks (Alignment)

    Agar dokumen terlihat estetik, gunakan fitur perataan di tab Home pada grup Paragraph.

    Align LeftContoh teks yang diratakan ke sisi kiri halaman untuk surat atau laporan.
    CenterContoh teks yang diratakan ke tengah untuk judul.
    Align RightContoh teks rata kanan untuk tanggal surat atau tanda tangan.
    JustifyContoh teks rata kiri-kanan yang membuat tulisan tampak kotak, rapi, dan profesional di kedua sisinya.
    NamaFungsi
    Align LeftRata kiri (standar untuk surat/laporan).
    CenterRata tengah (khusus untuk judul).
    Align RightRata kanan (biasanya untuk tanggal surat atau tanda tangan).
    JustifyRata kiri-kanan (membuat tulisan tampak kotak rapi dan profesional).

    Cara Mengoreksi dan Memindah Teks

    Jika ada kesalahan ketik, jangan panik. Gunakan metode berikut.

    Backspace
    Menghapus karakter di kiri kursor.
    Delete
    Menghapus karakter di kanan kursor.
    Memblok teks
    Klik kiri dan tahan, lalu geser mouse di atas kata yang ingin diubah. Setelah terpilih (berwarna biru), Anda bisa langsung mengganti warna, menebalkannya, atau menghapusnya.
    Undo
    Tekan Ctrl + Z jika Anda tidak sengaja menghapus sesuatu yang penting.

    Mengatur Jarak Baris (Line Spacing)

    Agar tulisan tidak terlalu rapat dan lelah dibaca:

    1. Blok tulisan Anda (atau tekan Ctrl + A untuk semua tulisan).
    2. Di tab Home, klik ikon Line and Paragraph Spacing (ikon garis dengan panah atas-bawah).
    3. Pilih angka 1.15 atau 1.5 untuk jarak yang paling nyaman dibaca.

    Menyimpan Hasil Kerja (Save)

    Jangan menunggu tulisan selesai baru disimpan. Lakukan ini sesegera mungkin:

    1. Klik File > Save.
    2. Pilih lokasi (misalnya Documents).
    3. Beri nama file yang spesifik.
    4. Klik Save.

    Sambil mengetik, tekan Ctrl + S secara berkala setiap beberapa menit untuk memastikan progres Anda aman jika komputer tiba-tiba mati.

    Saran tambahan. Untuk judul, gunakan fitur Bold (B) agar terlihat menonjol. Jika ada istilah asing (bahasa Inggris atau bahasa daerah), gunakan fitur Italic (I) untuk memiringkan kata tersebut.

    Mengatur Huruf dan Paragraf

    Mengatur huruf dan paragraf adalah inti dari pembuatan dokumen yang rapi dan profesional. Di Microsoft Word, hampir semua pengaturan ini berada di tab Home.

    Pengaturan Huruf (Grup Font)

    Grup ini berfungsi untuk mengubah tampilan estetika dari karakter atau kata yang Anda ketik.

    Jenis Huruf (Font Face)
    Klik kotak nama font (misalnya Calibri) untuk memilih gaya tulisan. Gunakan Times New Roman untuk dokumen resmi atau Arial untuk tampilan modern.
    Ukuran Huruf (Font Size)
    Klik angka di samping jenis huruf. Anda juga bisa menggunakan ikon A besar untuk memperbesar dan A kecil untuk memperkecil secara bertahap.
    Bold (B)
    Menebalkan teks. Tombol cepat: Ctrl + B.
    Italic (I)
    Memiringkan teks. Tombol cepat: Ctrl + I.
    Underline (U)
    Memberi garis bawah. Tombol cepat: Ctrl + U.
    Change Case (Aa)
    Mengubah teks menjadi huruf besar semua, huruf kecil semua, atau huruf besar di awal kata tanpa mengetik ulang.
    Font Color
    Klik ikon huruf A dengan garis bawah warna untuk mengubah warna teks.
    Text Highlight Color
    Memberi efek stabilo pada teks penting.

    Pengaturan Paragraf (Grup Paragraph)

    Grup ini mengatur bagaimana teks disusun dalam satu blok atau halaman.

    Perataan teks (Alignment)

    Align Left
    Rata kiri (standar surat).
    Center
    Rata tengah (untuk judul).
    Align Right
    Rata kanan (untuk tanggal atau tanda tangan).
    Justify
    Rata kiri-kanan (membuat dokumen terlihat sangat rapi di kedua sisi).

    Jarak baris dan paragraf (Line Spacing)

    • Klik ikon garis dengan panah atas-bawah (Line and Paragraph Spacing).
    • Pilih angka spasi (1.0, 1.15, 1.5, atau 2.0).
    • Remove Space After Paragraph: gunakan ini jika antar paragraf terasa terlalu renggang atau jauh.

    List (daftar berpoin)

    Bullets
    Menggunakan simbol (titik, centang, dll) untuk daftar acak.
    Numbering
    Menggunakan angka atau huruf untuk daftar yang berurutan.
    Multilevel List
    Digunakan untuk membuat sub-bab (contoh: 1., 1.1, 1.1.1).

    Indentasi (geser paragraf)

    Decrease Indent
    Menggeser paragraf ke kiri.
    Increase Indent
    Menggeser paragraf ke kanan.

    Pengaturan Lanjutan (Dialog Box)

    Jika Anda butuh pengaturan yang lebih detail, klik tanda panah kecil di pojok kanan bawah grup Font atau grup Paragraph.

    Dialog Font
    Mengatur efek khusus seperti Strikethrough (coret tengah), Superscript (pangkat atas seperti x2), dan Subscript (pangkat bawah seperti H2O).
    Dialog Paragraph
    Mengatur Special Indent (First Line) agar kalimat pertama otomatis menjorok ke dalam tanpa menekan Tab.

    Tips Profesional: Menggunakan Format Painter

    Jika Anda sudah mengatur satu judul dengan sangat rapi (jenis huruf, warna, ukuran) dan ingin menerapkan hal yang sama pada judul lain:

    1. Blok teks yang sudah rapi tersebut.
    2. Klik ikon sapu kecil (Format Painter) di pojok kiri atas tab Home.
    3. “Sapukan” atau blok teks baru yang ingin Anda ubah. Formatnya akan berubah seketika menjadi sama persis.

    Ringkasan Tombol Cepat (Shortcut)

    Rata TengahCtrl + E
    Rata Kiri-KananCtrl + J
    Membuka Menu FontCtrl + D
    Menambah Ukuran FontCtrl + ]
    Mengurangi Ukuran FontCtrl + [

    Membuat dan Mengelola Tabel

    Membuat dan mengelola tabel adalah keahlian penting di Microsoft Word untuk menyajikan data agar lebih terorganisir dan mudah dibaca.

    Cara Membuat Tabel

    Ada tiga cara utama untuk memasukkan tabel ke dalam dokumen.

    Metode Grid (cepat)

    Klik Insert > Table, lalu gerakkan kursor di atas kotak-kotak (grid) untuk menentukan jumlah kolom (ke samping) dan baris (ke bawah).

    Insert Table (presisi)

    Klik Insert > Table > Insert Table…. Masukkan angka spesifik untuk jumlah kolom dan baris yang diinginkan.

    Draw Table (bebas)

    Klik Insert > Table > Draw Table. Kursor berubah menjadi pensil, sehingga Anda bisa menggambar kotak tabel secara manual.

    Mengenal Tab Kontekstual (Table Tools)

    Saat Anda mengeklik di dalam tabel, akan muncul dua tab baru di bagian atas (Ribbon) yang hanya aktif untuk tabel.

    Table Design
    Mengatur estetika (warna, gaya garis, bayangan).
    Layout
    Mengatur struktur (menambah/menghapus baris, menggabungkan sel, ukuran kolom).

    Memodifikasi Struktur Tabel (Tab Layout)

    Bagian ini adalah “dapur” untuk mengubah bentuk tabel Anda.

    Menambah dan menghapus

    Insert Above/Below
    Menambah baris baru di atas atau di bawah kursor.
    Insert Left/Right
    Menambah kolom baru di samping kiri atau kanan kursor.
    Delete
    Menghapus sel, kolom, baris, atau seluruh tabel.

    Menggabungkan dan membagi sel

    Merge Cells
    Menggabungkan dua atau lebih sel menjadi satu (biasanya untuk judul tabel).
    Split Cells
    Membagi satu sel menjadi beberapa kolom atau baris baru.
    Split Table
    Memotong tabel menjadi dua bagian yang terpisah.

    Mengatur ukuran (Cell Size)

    AutoFit
    Menyesuaikan lebar kolom secara otomatis berdasarkan isi teks (AutoFit Contents) atau mengikuti lebar kertas (AutoFit Window).
    Distribute Rows/Columns
    Menyamakan ukuran tinggi semua baris atau lebar semua kolom agar seragam secara instan.

    Mengatur Tampilan dan Estetika (Tab Table Design)

    Agar tabel tidak terlihat kaku, Anda bisa memolesnya di sini.

    Table Styles
    Pilih desain instan yang sudah disediakan Word (warna selang-seling, garis tebal pada header, dll).
    Shading
    Memberi warna latar belakang pada sel atau baris tertentu secara manual.
    Borders
    Mengatur ketebalan garis, warna garis, atau bahkan menghilangkan garis tabel agar terlihat seperti daftar yang rapi.

    Pengaturan Teks di Dalam Tabel

    Teks di dalam tabel bisa diatur posisinya lebih detail daripada teks biasa.

    Alignment
    Di tab Layout terdapat 9 ikon perataan teks. Anda bisa mengatur teks agar tepat berada di tengah sel secara vertikal maupun horizontal (Align Center).
    Text Direction
    Mengubah arah tulisan menjadi miring atau tegak lurus (berguna untuk kolom yang sempit).
    Cell Margins
    Mengatur jarak aman antara tulisan dengan garis tepi sel agar tidak terlihat terlalu menempel.

    Tips dan Trik Tabel Profesional

    Mengulang header otomatis
    Jika tabel sangat panjang hingga berpindah halaman, klik baris judul, lalu di tab Layout pilih Repeat Header Rows. Judul tabel akan muncul otomatis di halaman berikutnya.
    Konversi teks ke tabel
    Jika Anda sudah mengetik daftar menggunakan Tab atau koma, ubah menjadi tabel instan melalui Insert > Table > Convert Text to Table.
    Menghitung data (Formula)
    Word bisa melakukan perhitungan dasar seperti di Excel. Klik sel tempat hasil muncul, pilih Layout > Formula, lalu masukkan rumus sederhana seperti =SUM(ABOVE).

    Shortcut berguna

    TombolFungsi
    TabBerpindah ke sel di sebelah kanan (atau membuat baris baru otomatis jika berada di sel terakhir).
    Shift + TabBerpindah ke sel di sebelah kiri.
    Alt + Shift + ↑ / ↓Memindahkan baris tabel ke posisi atas atau bawah tanpa perlu Cut-Paste.

    Menyisipkan Gambar, Shapes, dan Ikon

    Menambahkan elemen visual seperti gambar, shapes, dan ikon (pengganti Clipart di versi terbaru) akan membuat dokumen Anda jauh lebih menarik dan mudah dipahami.

    Menyisipkan Gambar (Pictures)

    Gambar bisa berasal dari perangkat Anda sendiri atau dari internet. Caranya, klik menu Insert > Pictures.

    This Device
    Mengambil foto yang tersimpan di komputer/laptop.
    Stock Images
    Koleksi gambar berkualitas tinggi gratis dari Microsoft.
    Online Pictures
    Mencari gambar langsung melalui mesin pencari Bing.

    Mengatur posisi (Layout Options)

    Saat gambar diklik, akan muncul ikon kecil di pojok kanan atas gambar.

    In Line with Text
    Gambar dianggap sebagai karakter teks (ikut bergeser jika ada ketikan).
    Square / Tight
    Teks akan mengelilingi gambar dengan rapi.
    Behind Text
    Gambar berada di belakang tulisan (seperti latar belakang).
    In Front of Text
    Gambar menutupi tulisan.

    Menggunakan Shapes (Bentuk Geometris)

    Shapes sangat berguna untuk membuat diagram, alur kerja (flowchart), atau dekorasi dokumen.

    1. Memasukkan. Klik Insert > Shapes, lalu pilih bentuk yang diinginkan (kotak, panah, lingkaran, dll).
    2. Menggambar. Setelah memilih bentuk, klik dan tahan (drag) di area dokumen untuk menentukan ukurannya.
    3. Memodifikasi. Klik pada shape tersebut, lalu gunakan tab Shape Format yang muncul.
    Shape Fill
    Mengubah warna bagian dalam.
    Shape Outline
    Mengubah warna, ketebalan, atau jenis garis tepi.
    Shape Effects
    Memberi efek bayangan (shadow), cahaya (glow), atau efek 3D.
    Add Text
    Klik kanan pada shape dan pilih Add Text untuk mengetik di dalamnya.

    Mengenal Ikon dan Ilustrasi (Pengganti Clipart)

    Pada versi Microsoft Word terbaru (2019 ke atas/Office 365), fitur “Clipart” telah digantikan oleh Icons dan Illustrations yang lebih modern dan bergaya minimalis.

    Cara memasukkan
    Klik Insert > Icons.
    Keunggulan
    Ikon ini berbasis vektor, artinya jika Anda memperbesar ukurannya sampai maksimal, gambar tidak akan pecah atau buram.
    Kustomisasi
    Anda bisa mengubah warna ikon menggunakan Graphic Fill di tab Graphics Format.

    Teknik Mengolah Gambar (Tab Picture Format)

    Setelah gambar masuk ke dokumen, Anda bisa mengeditnya secara instan tanpa aplikasi tambahan.

    Crop
    Memotong bagian gambar yang tidak diinginkan. Klik Crop, geser garis hitam di pinggir gambar, lalu tekan Enter.
    Remove Background
    Menghapus latar belakang foto secara otomatis (hanya menyisakan objek utama).
    Corrections
    Mengatur kecerahan (brightness) dan kontras agar gambar lebih jelas.
    Picture Styles
    Memberi bingkai, efek cermin, atau sudut tumpul pada gambar dalam satu klik.
    Artistic Effects
    Mengubah foto menjadi terlihat seperti sketsa pensil, lukisan cat air, atau efek mosaik.

    Mengatur Urutan dan Grup Elemen

    Jika Anda memiliki banyak gambar atau shapes yang bertumpuk:

    Bring Forward / Send Backward
    Digunakan untuk mengatur siapa yang berada di depan dan siapa yang di belakang.
    Selection Pane
    Klik Layout > Selection Pane untuk melihat daftar semua objek di halaman dan menyembunyikannya jika perlu.
    Group
    Agar beberapa shapes tidak berantakan saat dipindah, blok semua objek (tahan Shift sambil klik masing-masing objek), klik kanan, lalu pilih Group > Group. Sekarang mereka menyatu sebagai satu objek.

    Tips Mengatur Ukuran yang Proporsional

    Agar gambar atau shape tidak terlihat “peyang” (terlalu lebar atau terlalu tinggi):

    • Selalu tarik dari titik pojok (diagonal) saat mengecilkan atau memperbesar.
    • Tahan tombol Shift pada keyboard sambil menarik titik pojok tersebut agar rasio lebar dan tingginya tetap terjaga sempurna.

    Mengatur Tata Letak Halaman

    Menu Layout (atau Page Layout pada versi lama) adalah bagian paling krusial untuk menentukan bagaimana dokumen Anda akan terlihat saat dicetak. Pengaturan yang salah di sini bisa membuat tulisan terpotong atau format berantakan.

    Grup Page Setup (Fondasi Dokumen)

    Ini adalah bagian terpenting untuk mengatur spesifikasi kertas Anda.

    Margins

    Mengatur jarak antara tepi kertas dengan teks.

    Normal
    Standar (2.54 cm di semua sisi).
    Narrow
    Margin sempit (cocok untuk menghemat kertas).
    Custom Margins
    Jika Anda ingin memasukkan angka manual (misalnya Atas 3, Bawah 3, Kiri 4, Kanan 3 untuk standar laporan).

    Orientation, Size, dan Columns

    Portrait
    Kertas berdiri tegak.
    Landscape
    Kertas mendatar (cocok untuk tabel lebar atau sertifikat).
    Size
    Memilih ukuran fisik kertas, umumnya A4 atau F4/Folio.
    Columns
    Membagi teks menjadi beberapa kolom (seperti tampilan koran). Anda bisa memilih 2, 3, atau lebih.
    Penting. Selalu pastikan ukuran kertas di Word sama dengan kertas di printer Anda (umumnya A4 atau F4/Folio).

    Breaks

    Page Break
    Memaksa teks pindah ke halaman baru.
    Section Break
    Digunakan jika Anda ingin halaman 1 berbentuk Portrait dan halaman 2 berbentuk Landscape dalam satu file yang sama.

    Grup Paragraph (Indentasi dan Spasi)

    Berbeda dengan pengaturan di tab Home, di sini Anda bisa mengatur jarak secara lebih presisi menggunakan angka.

    Indent: Left
    Menggeser seluruh paragraf dari batas kiri.
    Indent: Right
    Menggeser seluruh paragraf dari batas kanan.
    Spacing: Before
    Memberi jarak kosong sebelum paragraf dimulai.
    Spacing: After
    Memberi jarak kosong setelah paragraf selesai. Atur ke 0 pt jika Anda ingin jarak antar baris benar-benar rapat.

    Grup Arrange (Mengatur Posisi Objek)

    Menu ini akan aktif jika Anda mengeklik gambar, shape, atau tabel.

    Position
    Menentukan di mana gambar berada di halaman (misalnya pojok kanan atas, tengah, atau bawah).
    Wrap Text
    Menentukan bagaimana teks “bersikap” terhadap gambar. Square: teks mengelilingi kotak gambar. In Front of Text: gambar menutupi tulisan.
    Bring Forward / Send Backward
    Mengatur tumpukan objek, mana yang di depan dan mana yang tertutup di belakang.
    Align
    Merapikan beberapa objek agar sejajar (rata kiri, rata tengah, atau rata atas) secara otomatis.
    Rotate
    Memutar gambar atau bentuk sesuai derajat yang diinginkan.

    Tips Mengatur Ukuran Kertas F4 (Folio) di Indonesia

    Karena ukuran F4 sering tidak ada di daftar standar Word, Anda bisa mengaturnya secara manual:

    1. Klik Layout > Size > More Paper Sizes.
    2. Pada tab Paper, masukkan Width (Lebar): 21.59 cm dan Height (Tinggi): 33 cm.
    3. Klik OK.

    Menggunakan Garis Baris (Line Numbers)

    Jika Anda membuat naskah hukum, puisi, atau naskah drama yang memerlukan referensi baris, klik Line Numbers > Continuous. Word akan memberi nomor di setiap baris tulisan di samping kiri secara otomatis.

    Saran tambahan. Sebelum mencetak, selalu gunakan fitur Print Preview (tekan Ctrl + P) untuk memastikan semua pengaturan di menu Layout sudah sesuai keinginan Anda agar tidak ada teks yang terpotong oleh batas margin.

    Menyimpan dan Mencetak Dokumen

    Menyimpan dan mencetak adalah tahap akhir yang paling krusial. Jika salah langkah, kerja keras Anda bisa hilang atau hasil cetaknya tidak sesuai harapan.

    Menyimpan Dokumen (Saving)

    Microsoft Word memiliki beberapa cara untuk mengamankan file Anda.

    Perbedaan Save dan Save As

    Save
    Ctrl + S. Digunakan untuk menyimpan perubahan pada dokumen yang sudah pernah disimpan sebelumnya.
    Save As
    F12. Digunakan untuk menyimpan dokumen untuk pertama kalinya, menyimpan dengan nama baru, atau mengubah format file (misalnya dari .docx ke .pdf).

    Cara menyimpan ke format PDF

    PDF sangat disarankan jika Anda ingin mengirim file agar tampilannya tidak berantakan saat dibuka di perangkat lain.

    1. Klik File > Save As.
    2. Pilih lokasi penyimpanan.
    3. Pada bagian Save as type, klik dan pilih PDF (*.pdf).
    4. Klik Save.

    Fitur AutoRecover

    Word memiliki fitur penyelamat jika laptop mati tiba-tiba. Pastikan fitur ini aktif:

    1. Klik File > Options > Save.
    2. Pastikan centang pada “Save AutoRecover information every X minutes” aktif (disarankan setiap 5 menit).

    Mencetak Dokumen (Printing)

    Sebelum menekan tombol cetak, masuklah ke tampilan Backstage View dengan menekan Ctrl + P.

    Mengatur pengaturan cetak (Settings)

    Di sisi kiri layar Print, terdapat beberapa opsi penting:

    Copies
    Tentukan berapa rangkap dokumen yang ingin dicetak.
    Printer
    Pilih mesin printer yang sedang aktif/tersambung.
    Print All Pages
    Print Selection: hanya mencetak teks yang diblok. Print Current Page: hanya halaman yang sedang tampil di layar. Custom Print: menentukan halaman tertentu (contoh: ketik 1-5, 10 untuk mencetak halaman 1 sampai 5 dan halaman 10 saja).
    One Sided / Both Sides
    Memilih mencetak satu muka atau bolak-balik (jika printer mendukung).
    Collated
    Jika mencetak banyak rangkap, fitur ini memastikan dokumen keluar berurutan (halaman 1, 2, 3), bukan (halaman 1, 1, 1).

    Memastikan layout benar (Print Preview)

    Di sisi kanan layar, Anda akan melihat Print Preview. Selalu periksa bagian ini:

    • Apakah ada teks yang terpotong di bagian pinggir? Jika ya, kecilkan margin di menu Layout.
    • Apakah ada halaman kosong di akhir? Jika ya, hapus baris kosong di dokumen Anda.
    • Gunakan ikon Zoom di pojok bawah untuk melihat detail tulisan.

    Jika Anda memiliki akun Microsoft, simpanlah file ke OneDrive.

    Keuntungan

    Cara
    Klik File > Save As > OneDrive.
